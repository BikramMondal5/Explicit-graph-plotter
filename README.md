# 📊 Explicit graph plotter

Welcome to the **Equation Plotter** project! This Python project helps students and enthusiasts to plot the graph of any explicit equation using the powerful **Matplotlib** library. 📈

### 🌟 Features
- 🖍️ **Interactive Graphs**: Visualize any explicit equation effortlessly.
- 🎯 **Accurate Results**: Generates precise graphs that improve your understanding.
- 📚 **Educational Aid**: A valuable tool for students learning mathematics.

### 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/BikramMondal5/Explicit-graph-plotter.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Explicit-graph-plotter
   ```
3. **Install required libraries:**
   ```bash
   pip install matplotlib numpy
   ```
4. **Run the python script:**
   ```bash
   python main.py
   ```
